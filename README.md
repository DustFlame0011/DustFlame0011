## Featured Projects

### [Predictive Maintenance & Anomaly Detection for Manufacturing Equipment](https://github.com/DustFlame0011/manufacturing-predictive-maintenance)
Compared supervised (Random Forest, XGBoost) vs. unsupervised (Isolation Forest) approaches to predict equipment failure from sensor data on a highly imbalanced dataset (3.39% failure rate). Best model (XGBoost) reached **0.76 F1 / 75% recall** on the failure class, validated with stratified cross-validation and multiple random seeds — then deployed as a containerized FastAPI service.
`Python` `scikit-learn` `XGBoost` `FastAPI` `Docker`

### [Super AI Engineer S6 — FahMai Thai RAG Challenge](https://github.com/DustFlame0011/-Super-AI-Engineer-S6-FahMai-Thai-RAG-Challenge)
Built a Retrieval-Augmented Generation system to answer Thai-language multiple-choice questions from a store knowledge base. Iterated from a 0.06 baseline to a **0.71 public / 0.82 private score (+144 leaderboard positions)** by debugging retrieval and prompt bugs, switching to markdown-aware chunking, and adding query expansion + majority voting across two Thai LLMs.
`BGE-M3` `BM25` `pythainlp` `RAG` `Google Colab`
